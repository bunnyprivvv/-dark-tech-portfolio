## 🔒 Security Hardening & Protocols
This portfolio is engineered according to strict security protocols to prevent script injections and unauthorized connections:
*   **Content Security Policy (CSP):** Hardened `<meta>` header locks down script execution scope. Only verified dependencies like Web3Forms, Spline 3D Scene assets, and Google/Fontshare typography domains are permitted.
*   **Encrypted Communications:** The contact module integrates a fully non-blocking React AJAX protocol communicating via a secure token-routing TLS channel backed by Web3Forms.

## ⚙️ Development & Local Setups

### Prerequisites
*   Node.js (v18+)
*   npm (v9+)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/bunnyprivvv/-dark-tech-portfolio.git
   cd -dark-tech-portfolio
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
